If set, validates this one claim directly instead of matching the Test Data claim inventory by the template's State/LOB applicability — useful for testing a template that doesn't have a matching test-data claim yet.
Most templates in the index are marked "Interactive", not "On Demand" — picking one automatically opens a real Microsoft sign-in popup that you need to complete (email, password, MFA) in the browser window this run opens. The few On-Demand templates run fully unattended. Nothing to toggle — this is detected per template automatically.
Scenarios to run per template (optional)
How many of the template's own LOB/State-matched scenarios to actually run — NOT the same as "concurrently" below, which only controls how many run at once, not how many run in total. Leave at the default to run every matched scenario (up to 3).
Scenarios run 2 at a time per template automatically (a template with only 1 matching scenario just uses 1 worker — nothing to toggle here). With Interactive templates enabled, more than one Azure sign-in/MFA prompt or "Complete this draft?" dialog can appear at the same time — a saved sign-in session usually clears these on its own, but the first run of the day may need you to watch more than one window.
